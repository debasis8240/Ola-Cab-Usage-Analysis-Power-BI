# 🚖 OLA Ride Booking Analysis Dashboard | Power BI

A comprehensive **Power BI dashboard** developed to analyze OLA ride bookings, customer behavior, booking status, revenue, cancellations, ride distance, payment methods, and driver performance. The dashboard transforms ride booking data into interactive visualizations, enabling business stakeholders to monitor operational efficiency, customer satisfaction, and overall business performance.

---

# 📌 Project Overview

This project provides an interactive OLA Ride Booking Dashboard that offers valuable insights into ride operations, customer demand, booking trends, cancellations, revenue generation, and driver performance. The dashboard helps identify business opportunities, improve customer experience, and optimize fleet operations.

The dashboard includes analysis of:

- 🚖 Ride Booking Performance
- 💰 Revenue Analysis
- ❌ Ride Cancellation Analysis
- 📍 Pickup & Drop Location Analysis
- 🚘 Vehicle Type Performance
- 💳 Payment Method Analysis
- ⭐ Driver & Customer Ratings
- 📈 Business KPIs

---

# 🚀 Project Objectives

This dashboard answers key business questions such as:

- How many rides were successfully completed?
- What is the total booking revenue?
- Which vehicle type is booked the most?
- Why are rides getting cancelled?
- Which payment method is most preferred?
- Which pickup and drop locations have the highest demand?
- How satisfied are customers and drivers?
- What is the average ride distance?
